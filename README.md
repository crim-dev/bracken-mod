# Bracken Mod

A collection of files used for converting (the Bracken Pack)[https://github.com/BrackenStrike/BrackenPack] into a mod.

This repository has two submodules, so it should be cloned with the appropriate flag :

```
git clone https://github.com/crim-dev/bracken-mod --recurse-submodules
```

## Versions

### Releases
- main

### Legacy
For the sake of convenience we have decided to keep track of four versions :

| Version | Matching dp+rp versions  |
|---------|------------|
| 26.1.2  | v127 / v73 |
| 1.21.11 | v126 / v72 |
| 1.21.1  | v112 / v59 |
| 1.20.1  | v90 / v35  |

Each one has its own branch on this repository.

All four of these versions are intended to receive full backports of the latest features of the Bracken Pack. I cannot guarantee when that will happen, but I certainly intend to do that progressively. Any help is welcome.

## Dependencies

Due to the nature of this mod (basically a datapack + resourcepack disguised as a mod), we always depend on the Fabric API.

Nothing else, thankfully.

## Scripts
The ./scripts directory contains bash scripts used to assemble the datapack, resource pack (./assets) and mod.

I don't intend to write equivalent .bat files (since we are most likely going to start using Gradlew instead should we decide to add Java code), but if you decide to make a pull request that adds some, I'm not going to refuse it.
